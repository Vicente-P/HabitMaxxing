# API — Registros y estadísticas

> ⚠️ **Documento en construcción.** EP-03 (Registro diario) y EP-04 (Estadísticas) están pendientes de implementación.

---

## Endpoints planeados

### Registrar cumplimiento diario

```
POST /api/habits/:id/logs
```

### Obtener registros de un hábito

```
GET /api/habits/:id/logs
```

### Estadísticas de cumplimiento

```
GET /api/habits/:id/stats
```

### Heatmap de progreso

```
GET /api/habits/:id/heatmap?year=2026
```
