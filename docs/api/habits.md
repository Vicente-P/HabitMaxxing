# API — Hábitos

> ⚠️ **Documento en construcción.** EP-02 (Gestión de hábitos) está pendiente de implementación.

---

## Endpoints planeados

### Listar hábitos del usuario

```
GET /api/habits
```

### Obtener un hábito

```
GET /api/habits/:id
```

### Crear hábito

```
POST /api/habits
```

### Actualizar hábito

```
PATCH /api/habits/:id
```

### Eliminar hábito

```
DELETE /api/habits/:id
```
